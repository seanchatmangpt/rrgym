# Fortune-5 acceptance court

A release may be called Fortune-5-ready only when all of the following have independent evidence:

1. Exact-head test matrix executes on every supported runtime.
2. Mutation/property/fuzz tests cover transition invariants and receipt tamper detection.
3. Public-domain ruleset provenance and current-authority licensing boundary are reviewed.
4. Full GymAct adapter executes through real injected authority + independent verifier + OCEL replay.
5. ggen pack executes with the pinned ggen version, receipt verify, replay, and gate sabotage refusal.
6. Planner league executes at least 50 heterogeneous policies across chair/member/adversarial roles.
7. CMCA allocation is differential-tested against exhaustive search on tractable worlds.
8. Red-team suite demonstrates agenda/deadlock/manipulation attacks and recovery.
9. SBOM, SLSA provenance, dependency/license scan, secret scan, CodeQL, and signed release artifacts are green.
10. No claim exceeds evidence standing.

The v26.8.12 bootstrap implementation intentionally does not manufacture evidence for unavailable external execution surfaces.
