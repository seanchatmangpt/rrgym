# Research program

Primary falsifiable thesis: **institutions can be benchmarked like algorithms**.

Experimental tensor:
`M[planner, role, world, ruleset, information_partition, authority]`.

Primary outcomes: decision quality, regret, latency, manipulation resistance, minority protection, participation, procedural efficiency, resilience, and possibility retention.

Prior-art fence: formal Robert's Rules automation, corporate-board agent simulation, social-choice multi-agent systems, and modern institution-constrained LLM deliberation all pre-exist `rrgym`. Novelty, if established, must be claimed at the closure: executable parliamentary world law + heterogeneous planner league + cross-play + institutional red teaming + DfCM/CMCA + receipted authority/evidence.
