# Security and authority policy

`rrgym` is a simulation/governance kernel, not an ambient actuator.

- `DO` is denied by default.
- Authority is injected; planners cannot mint grants.
- Refusals are typed and receipted.
- Checkpoints are identity-bound.
- No network, shell, credential, email, calendar, voting-service, or corporate-system actuator is included in the core.
- Production integrations must route consequence through the ecosystem BRCE/GymAct authority boundary.

Report security issues privately to the repository owner.
